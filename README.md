# Шайтан-машина

Система случайного выбора учеников для учителей. Помогает равномерно опрашивать учеников на уроках.

## Технологический стек

- **Backend**: PHP 7.4+
- **База данных**: MySQL 8.0+
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Безопасность**: Prepared statements, password hashing, XSS protection

#
## Использование

### Первый запуск

1. Откройте сайт в браузере
2. Зарегистрируйте нового пользователя
3. **Важно**: При регистрации пользователя с именем `Slavik10` он автоматически получит права администратора

### Основные функции

1. **Создание классов**: После регистрации создайте классы
2. **Добавление учеников**: В разделе "Управление учениками" добавьте учеников в класс
3. **Проведение урока**: Выберите класс и начните урок
4. **Выбор ученика**: Нажмите кнопку "Выбрать случайного ученика"
5. **Отметка отсутствующих**: Кликните по ученику, чтобы отметить его отсутствующим

### Режим "свои" (подкрутка)

Только для администратора (`Slavik10`):

1. Перейдите в админ-панель
2. Выберите класс
3. Выберите учеников, для которых нужно активировать режим
4. Установите время действия (15/30/45 минут)
5. Активируйте режим

Когда режим активен, выбранные ученики не будут выпадать при случайном выборе до последнего.

### Умный выбор

В настройках класса можно включить "Умный выбор" (взвешенная вероятность):
- Ученики, которые давно не выходили, имеют больший шанс быть выбранными
- Учитывается приоритет ученика
- Учитывается количество предыдущих выходов

### Экспорт/Импорт учеников

- **Экспорт**: В разделе управления учениками нажмите "Экспорт JSON" - сохранится файл со всеми учениками и их статистикой
- **Импорт**: Нажмите "Импорт" и вставьте данные в формате JSON или текстовом формате (номер, имя, фамилия)

## Безопасность

- Все SQL-запросы используют prepared statements
- Пароли хешируются с помощью `password_hash()`
- Защита от XSS через `htmlspecialchars()`
- Проверка авторизации на каждой странице
- Сессии настроены на 1 год (365 дней)

## Особенности

- **Темная/светлая тема**: Переключатель темы в правом верхнем углу
- **Цветовые схемы классов**: Каждый класс может иметь свой цвет
- **Адаптивный дизайн**: Работает на мобильных устройствах
- **Анимации**: Плавные переходы и эффекты при выборе ученика
- **Расписание**: Система может подсказывать, какой класс по расписанию

## Настройка локального конфига

Для запуска создайте `includes/config.php` на основе `includes/config.example.php`.

1. Скопируйте `includes/config.example.php` в `includes/config.php`.
2. Укажите доступ к БД.
3. При необходимости поменяйте `SITE_URL` и `ADMIN_USERNAME`.
4. Не коммитьте `includes/config.php`.
